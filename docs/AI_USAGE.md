# AI usage disclosure

Codex assisted with translating the supplied challenge analysis into the initial repository structure, SQLite schema, documentation, and schema tests.

AI-generated work is not treated as automatically correct. Each phase records actual commands and test outcomes in `WORKFLOW_LOG.md`. The candidate remains responsible for reviewing the design, understanding the business rules, running the software, correcting errors, and accurately describing what was personally verified. No external AI API is required by the application itself.

The chronological user prompt is recorded in `prompts/prompt_history.md`. Future development prompts should be appended before or during their corresponding phase.
